# Pulsify

Interactive AMOLED live wallpapers that react to touch and music — web prototype (installable PWA).

**Install on Android:** open the site in Chrome → menu ⋮ → *Add to Home screen* / *Install app*.

Wallpapers: Buddy Crew (3D characters built in Three.js), Orbit Unlock super wallpaper, Midnight Hypercar, Solar Core, animals, instruments, water, cosmos and more.
